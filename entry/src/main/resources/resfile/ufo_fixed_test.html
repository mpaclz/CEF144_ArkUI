UFO equivalent test — bounded ring buffer

Functionally equivalent to testufo.com's multi-framerate test: same three UFO rows (120/60/30 fps) at identical pixels-per-second, same star field, same refresh-rate detection cadence (validate every 100 ms). The one difference is the detector's sample store. testufo.com appends to arrays that grow to MAXSTORE=240,000 and runs an O(n) least-squares pass over them, so per-cycle cost rises with uptime until a 41 ms spike lands inside an 8.33 ms frame budget. This page keeps a fixed-capacity ring buffer, so validation is O(CAP) — constant regardless of uptime. Toggle the second button to run the original unbounded algorithm side by side and watch the frame rate collapse while the bounded one stays flat.
