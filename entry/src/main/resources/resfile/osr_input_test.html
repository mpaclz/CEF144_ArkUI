2. 多触摸点测试 Multi-Touch

用两个手指同时触摸下方绿色区域，双指捏合或展开：

双指触摸此区域 Pinch with two fingers
双指捏合/展开缩放我 Pinch to zoom
等待触摸事件...
期望现象：
1. 双指触摸后，"等待触摸事件..." 变为 "双指触摸开始 dist=XXX"
2. 双指展开 → 紫色方块变大，日志显示 "缩放: 1.5x" 等
3. 双指捏合 → 紫色方块变小，日志显示 "缩放: 0.8x" 等
4. 整个网页不应被缩放，只有紫色方块变化
如果日志不变且整个网页被缩放，说明触摸事件未到达页面。
