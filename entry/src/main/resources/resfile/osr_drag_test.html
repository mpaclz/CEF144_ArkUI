OSR 拖放测试页 Drag & Drop Test

1. 文字拖放 Text Drag & Drop

拖拽蓝色文字块到下方虚线框释放。测试文字类型数据的拖拽源→目标全链路。

Hello World 你好世界
拖放文字到此处 Drop text here
  1. 长按（触摸）或左键按住（鼠标）上方蓝色文字块
  2. 拖动到虚线框内
  3. 在虚线框内松手释放
预期：虚线框内出现绿色结果条，显示 "Text: 你好世界"。

拖放链接到此处 Drop link here
  1. 长按上方绿色链接文字
  2. 拖动到虚线框内

预期：绿色结果条显示 "URL: https://example.com"。

填入输入框的文字

  3. 在输入框内松手释放
预期：输入框中填入拖放的文字内容。

5. 拖出到系统 Drag Out to System

从网页拖拽文字到本应用外的目标（如另一 App 的输入框）。仅测试拖拽源。

拖我到系统输入框 Drag me outside
  1. 长按上方蓝色文字块开始拖拽
  2. 拖出到本应用外（如系统浏览器的地址栏、备忘录的输入框）
  3. 在外部目标处松手释放
预期：系统拖拽预览出现并跟随手指/鼠标。在外部输入框释放后，文字被粘贴到外部目标中。
注意：需要分屏或悬浮窗模式才能跨应用拖放。

6. 外部拖入 Drop from External

从其他 App 选中文字，拖到本页虚线框释放。仅测试拖放目标。

从外部 App 拖放到此处 Drop from external app
  1. 切换到其他 App（如系统浏览器），选中一段文字
  2. 长按选中的文字开始拖拽
  3. 拖回到本应用的本节虚线框内
  4. 在虚线框内松手释放
预期：外部文字出现在绿色结果条中。
注意：需要分屏或悬浮窗模式。触摸屏可能需要系统支持跨应用拖拽。

7. 图片拖放 Image Drag & Drop

拖拽下方图片到外部应用（文件管理器、图片查看器）或拖回本页虚线框。测试图片文件拖出与拖入。

拖放图片到此处 Drop image here
  1. 长按上方图片开始拖拽
  2. 拖到虚线框内释放（测试自拖拽），或拖到外部应用释放（测试拖出到系统）
预期：拖到虚线框显示文件名；拖到文件管理器可保存图片文件。
注意：拖出到系统需要分屏或悬浮窗模式。

8. 文件拖入 File Drag In

从文件管理器拖拽文件到下方虚线框。测试从系统接收文件类型的拖放。

从文件管理器拖放文件到此处 Drop files here
  1. 打开文件管理器，选中一个文件（图片、文本等）
  2. 长按文件开始拖拽
  3. 拖到本节虚线框内释放
预期：虚线框内显示文件名和大小。
注意：需要分屏或悬浮窗模式才能跨应用拖放。
